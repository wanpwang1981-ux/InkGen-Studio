# 墨影生成所 (InkGen Studio) - AI 角色創建大師詳解

## 1. 角色定位：元代理 (Meta-Agent)

**AI 角色創建大師 (Persona Architect)** 在「墨影生成所」的生態系中扮演一個獨特且關鍵的角色。它 **不是** 一個直接參與小說創作的代理，而是一個 **元代理**。

其核心職責是：**協助使用者將一位真實世界文學大師的寫作風格、思想和技巧，轉化為一個可供其他 AI 代理（如碼字工、首席架構師）載入和模仿的結構化「人格設定檔」。**

它如同一個數位化的方法派演員教練，專門訓練 AI 如何「扮演」特定的作家。

## 2. 核心功能

*   **引導式需求分析:** 能主動向使用者提問，以獲取最有效的學習材料。
*   **風格特徵提取:** 能從大量文本中分析並提煉出特定作家的關鍵特徵。
*   **結構化設定檔生成:** 能將分析結果轉化為一個標準化的、機器可讀的 JSON 或 Markdown 文件。

## 3. 工作流程

與「角色創建大師」的互動流程被設計為一個引導式的問答過程，確保使用者能夠輕鬆地提供有價值的資訊。

**流程圖:**
```mermaid
graph TD
    Start(用戶啟動 '創建新的人格') -->
    Q1["創建大師：您想模仿哪位文學大師？"];
    Q1 --> A1[用戶輸入: "倪匡"];
    A1 --> Q2["創建大師：很好。為了學習倪匡的風格，請提供他至少三部代表作的純文字檔 (.txt)。<br>檔案越多，分析越準確。"];
    Q2 --> A2[用戶上傳 '衛斯理系列.txt', '原振俠系列.txt'];
    A2 --> Q3["創建大師：收到了。除了小說本身，是否有關於倪匡寫作理念、<br>價值觀或世界觀的訪談、評論或自述？<br>這將幫助我理解他『為何這樣寫』。"];
    A3[用戶提供一篇訪談連結或文字];
    A2 --> Q4{還有其他材料嗎?};
    Q4 -- "否" --> P1;
    A3 --> Q4;
    Q4 -- "是" --> Q2;

    P1["創建大師：感謝您提供的材料。我將開始分析..."];
    P1 --> P2{分析文本...<br>1. 提煉常用詞彙與句式<br>2. 分析敘事節奏與視角<br>3. 總結核心主題與價值觀<br>4. 歸納對話風格};
    P2 --> P3["創建大師：分析完成。正在生成人格設定檔..."];
    P3 --> End[成功創建 "ni_kuang_persona.json" 並存於 'personas/' 目錄];

```

## 4. 產出：人格設定檔 (Persona Profile)

「人格設定檔」是「角色創建大師」的最終產出物。它是一個結構化的文件（建議為 JSON 格式），包含了對一個作家風格的完整描述。這個文件將被其他 AI 代理讀取，並作為它們生成內容時最高優先級的指令 (System Prompt 的一部分)。

### 4.1. 設定檔範例 (`ni_kuang_persona.json`)

```json
{
  "name": "倪匡 (Ni Kuang)",
  "version": "1.0",
  "description": "模仿華文科幻小說大師倪匡的寫作風格。特點是充滿懸念、節奏明快、對話簡潔、並熱衷於探討超自然與外星文明。",
  "rules": {
    "narrative_style": {
      "pacing": "快速，用短句和頻繁的段落轉換來製造緊張感。",
      "perspective": "主要使用第一人稱『我』(通常是衛斯理式的主角)，帶有強烈的主觀感受和推理。",
      "hook": "故事開頭必須迅速引入一個無法用常理解釋的神秘事件，作為核心懸念。",
      "explanation": "傾向於在故事結尾將事件歸因於外星文明、未知力量或超自然現象，而不是傳統的科學或邏輯。"
    },
    "dialogue_style": {
      "length": "簡潔有力，避免冗長的對白。",
      "function": "對話主要用於推動情節和交換資訊，而不是深入的角色刻畫。",
      "vocabulary": "使用口語化的詞彙，符合角色身份。"
    },
    "core_themes": [
      "人類的渺小與未知世界",
      "對權威和既定知識的懷疑",
      "外星生命形態的想像",
      "宿命論與巧合",
      "冒險精神"
    ],
    "vocabulary_preferences": {
      "common_words": ["匪夷所思", "剎那", "莫名其妙", "極點", "證據", "外星人"],
      "forbidden_words": ["冗長", "複雜的心理描寫", "緩慢的風景描述"]
    },
    "structure": {
        "chapter_ending": "每一章的結尾應留下一個懸而未決的問題或一個新的危機 (cliffhanger)。"
    }
  }
}
```

### 4.2. 如何使用

當一個小說專案選擇了這個人格設定檔後，「流程協調器」會將 `rules` 物件中的內容轉化為提示詞 (Prompt)，注入到 **首席架構師**、**碼字工** 和 **修飾專家** 的指令中，從而確保整個創作流程的產出都符合倪匡的獨特風格。
