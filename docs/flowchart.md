# 墨影生成所 (InkGen Studio) - 核心工作流程

## 1. 總覽

本文件旨在以視覺化流程圖的方式，詳細闡述「墨影生成所」從零到一創作一部網路小說的完整工作流程。此流程涵蓋了從專案初始化、人格設定、大綱規劃到章節寫作與審核的每一個環節。

## 2. 總體流程圖

此流程圖分為四個主要階段：
*   **階段 0: 人格準備 (一次性)**
*   **階段 1: 小說初始化**
*   **階段 2: 宏觀規劃 (大綱與主旨)**
*   **階段 3: 章節生產迴圈**

## 3. 流程步驟詳解

### 階段 0: 人格準備 (Persona Preparation)
*   這是一個可選的、一次性的前置步驟。
*   **觸發:** 當使用者想要 AI 模仿一位特定作家（如倪匡、金庸）的風格時。
*   **流程:**
    1.  使用者與 **AI 角色創建大師 (Persona Architect)** 進行互動。
    2.  根據「創建大師」的指引，使用者提供這位作家的代表作品、訪談等學習材料。
    3.  「創建大師」分析這些材料，提煉出其寫作風格、詞彙、價值觀等，並生成一個結構化的「人格設定檔」（例如 `ni_kuang.json`）。
    4.  這個設定檔被保存在 `personas/` 目錄中，供後續任何小說專案隨時調用。

### 階段 1: 小說初始化 (Novel Initialization)
*   **觸發:** 使用者決定開始一部新小說的創作。
*   **流程:**
    1.  使用者透過命令列介面 (CLI) 提供新小說的名稱。
    2.  系統提示使用者從已配置的語言模型 (LLM)列表中選擇一個。
    3.  系統提示使用者從 `personas/` 目錄中選擇一個「人格設定檔」，或選擇使用不帶特定風格的「預設人格」。
    4.  **流程協調器 (Orchestrator)** 根據這些資訊，在 `novels/` 目錄下創建對應的小說專案資料夾，並初始化 Git 倉庫和空的向量知識庫。

### 階段 2: 宏觀規劃 (Macro-level Planning)
*   **觸發:** 小說初始化完成後自動開始。
*   **流程:**
    1.  **首席架構師 (Lead Architect)** 載入選定的人格設定檔。
    2.  它根據小說名稱（主題），並融合人格的風格，生成故事的核心概念，包括世界觀、主要角色、故事主旨等。
    3.  接著，它會產出一份詳細的、分章節的故事大綱。
    4.  協調器將這些宏觀規劃的成果儲存起來，作為整個創作過程的「北極星」。

### 階段 3: 章節生產迴圈 (Chapter Production Loop)
*   **觸發:** 宏觀規劃完成後，從第一章開始自動執行。這是系統運作的核心。
*   **流程:**
    1.  **碼字工 (Writer)** 獲取當前章節的大綱、前面章節的內容摘要以及從知識庫中檢索到的相關設定。
    2.  它依據這些資訊，並遵循載入的人格風格，撰寫出約 5000 字的初稿。
    3.  **修飾專家 (Refiner)** 接手初稿，進行語句潤飾、錯別字修正和風格一致性檢查，產出潤飾稿。
    4.  **專業讀者 (Reader)** 對潤飾稿進行審核。它會從多個維度進行評估：是否符合大綱？情節是否合理？人物是否ooc？是否符合網路小說的爽點節奏？
    5.  **決策點:**
        *   **如果 (If) 不合格:** 「讀者」會產出具體的、可執行的修改指令（例如：「情節推進太慢，請在段落三增加一個衝突點」），然後將任務連同指令發回給「碼字工」，開始新一輪的「寫作-潤飾-審核」迴圈。
        *   **如果 (If) 合格:** 該章節被標記為「已批准」。
    6.  協調器將「已批准」的章節正式存檔，並執行 `git commit`，完成版本儲存。
    7.  協調器觸發一個程序，自動從新章節中提取關鍵資訊（如新角色、新地點、重要情節轉折），並更新到向量知識庫中。
    8.  系統檢查是否還有下一章的大綱。如果有，則自動開始下一章的生產流程；如果沒有，則小說創作完成。
